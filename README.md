# 🧠 UpSkilling

UpSkilling é um sistema de evolução pessoal inspirado em MMORPGs clássicos
(como Tibia) e jogos de simulação (como The Sims) onde habilidades evoluem conforme o uso,
quests geram recompensas e a vida real vira um RPG.

## 🎯 Conceitos principais
- Skills com XP incremental
- Quests com recompensas (XP ou multiplicadores)
- Logs como fonte da verdade
- Dashboard estilo jogo clássico

## 🗂 Estrutura do repositório
- `/docs` → documentação do sistema
- `/blogger` → template e widgets do Blogger
- `/apps-script` → backend (Google Apps Script)
- `/assets` → imagens, sons, ícones

## 🔗 Stack
- Frontend: Blogger + HTML/CSS/JS
- Backend: Google Apps Script
- Banco de dados: Google Sheets
